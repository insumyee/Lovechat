上传文件：index.html、.nojekyll。README.txt 和 .gitignore 可一起上传。
index.html 必须位于网站发布目录的根目录。这是完整的单文件网页，不需要Node、依赖安装或构建。
此文件夹不包含APK、安卓工程、签名证书、密码、聊天备份或电脑配置。不要上传 E:\小屋聊天 整个工作目录。

本次只同步分享版已有功能：
- 自动来信改为8～16条字卡；回信继续保持8～16条。
- 手动拨打电话不再推迟已安排的3～7天自动来电。
- 聊天字卡库使用统一浅灰折叠排版，原有搜索、分组、屏蔽和删除保留。
- 完整备份、设置备份和聊天导出加入等待弹窗；备份JSON使用工作线程生成。
- 引用显示保持分享版原样。
没有添加完整版独有功能。没有加入安卓原生通知代码。

使用与数据：
每位访问者的数据保存在自己的浏览器，不会随网页文件自动上传到GitHub。
默认没有个人头像、聊天背景、聊天记录或信件，默认昵称“我”“梦角”。
这是公开网页源码，别人可以查看和下载代码。自行添加的远程图片或CSS可能向对应地址发送请求。
清理浏览器数据、更换浏览器或更换网站域名，可能无法继续访问原来的本地数据，请定期完整备份。
浏览器页面关闭后不保证继续计时或弹系统通知；APK后台功能不属于此网页包。
后续更新只替换发布的index.html；不要把个人备份JSON加入仓库。
